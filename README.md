# WorkNLP

**WorkNLP** — модуль для маскирования конфиденциальной информации в текстовых файлах.

Проект был создан в июле 2025 года в рамках производственной практики. Это моя первая полноценная программная работа, выполненная не просто как учебное упражнение, а под реальную прикладную задачу компании из банковской сферы.

Модуль предназначен для обработки `.txt`-файлов: на вход подаётся текст, содержащий персональные или чувствительные данные, а на выходе создаётся новая версия файла, в которой такая информация заменена на специальные маркеры.

## Назначение

Основная задача проекта — автоматическое обезличивание текстов без отправки данных во внешние сервисы.

Это было важно, потому что программа разрабатывалась для работы с конфиденциальной информацией, где недопустима передача исходного текста в интернет или сторонние облачные сервисы.

Проект лучше рассматривать именно как модуль или прототип сервиса маскирования, который можно встроить в более крупную систему обработки документов.

## Что маскируется

Модуль умеет находить и заменять разные типы чувствительных данных:

- ФИО;
- номера телефонов;
- адреса электронной почты;
- паспортные данные;
- физические адреса;
- суммы денег;
- даты;
- некоторые другие именованные сущности.

## Как работает

В проекте используется комбинированный подход:

1. NLP-модель на базе Transformers ищет именованные сущности в тексте.
2. Регулярные выражения дополнительно обрабатывают данные с формальной структурой: телефоны, email, паспорта, суммы, даты и адресные элементы.
3. Найденные данные заменяются на маркеры вида `<ФИО>`, `<телефон>`, `<email>`, `<паспорт>`, `<адрес>`, `<сумма>`, `<дата>`.
4. После обработки рядом с исходным файлом создаётся новый файл с постфиксом `-masked`.

Например, если на вход подаётся файл:

    text.txt

то результат сохраняется как:

    text-masked.txt

## Пример

Исходный текст:

    Привет, Константин! Твой адрес — улица Ленина, дом 13. Телефон: +7 910 746-56-90.

После обработки:

    Привет, <ФИО>! Твой адрес — <адрес>. Телефон: <телефон>.

## Запуск

1. Установить зависимости из `requirements.txt`.
2. Убедиться, что рядом с кодом находится папка `model` с локальной моделью.
3. Запустить файл `main.py`.
4. В открывшемся окне выбрать `.txt`-файл.
5. Получить результат в файле `<имя>-masked.txt`.
