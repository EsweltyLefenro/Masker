
# Masker — Offline Sensitive Data Masking

**Masker** — Python-приложение для автоматического маскирования конфиденциальной информации в текстовых документах с использованием методов обработки естественного языка (NLP).

Проект разработан в июле 2025 года в рамках производственной практики в **AI-подразделении ООО «СберКорус»**. Основная задача заключалась в создании локального инструмента для обработки документов, содержащих персональные и другие чувствительные данные, без передачи информации внешним сервисам.

## Возможности

- **Named Entity Recognition (NER)** — обнаружение имён, географических объектов и других именованных сущностей с помощью предварительно обученной нейросетевой модели.
- **Регулярные выражения** — распознавание телефонных номеров, email, паспортных данных, денежных сумм, дат и элементов адресов.
- **Обработка длинных текстов** — использование скользящего окна с перекрытием токенов для преодоления ограничений длины входа модели.
- **Локальная обработка** — работа с моделью без облачных API и передачи документов в интернет.
- **Графический интерфейс** — выбор и обработка `.txt`-файлов через Tkinter.

## Пример работы

**Исходный текст:**

```text
Привет, Константин! Твой адрес — улица Ленина, дом 13. Телефон: +7 910 746-56-90.
```

**После обработки:**

```text
Привет, <ФИО>! Твой адрес — <адрес>. Телефон: <телефон>.
```

Результат сохраняется рядом с исходным документом в отдельном файле с суффиксом `-masked.txt`.

## Технологии

| Технология | Назначение |

| Python | Основная логика приложения |

| Threading | Фоновая загрузка модели |

## Реализация и оптимизация

В приложении объединены два подхода к маскированию: нейросетевое распознавание сущностей и поиск по регулярным выражениям.

Для повышения производительности использовались квантование модели, оптимизация процесса загрузки и обработка текста отдельными перекрывающимися фрагментами.

**Результаты оптимизации во время практики:**

- Время запуска сократилось приблизительно с **30 до 4–5 секунд**.
- Время обработки тестового текста сократилось приблизительно с **10 до 1 секунды**.
- Реализована поддержка текстов, превышающих ограничение одного входного окна нейросети.

Показатели получены в исходном окружении разработки и могут отличаться на других устройствах.

## Запуск

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/EsweltyLefenro/Masker.git
   cd Masker
   ```

2. Установить зависимости в совместимом Python-окружении:

   ```bash
   pip install -r requirements.txt
   ```

3. Разместить совместимую локальную модель и токенизатор в каталоге `model/`, включая файл `model_quantized.pt`.

4. Запустить приложение:

   ```bash
   python main.py
   ```

5. Выбрать `.txt`-файл в графическом интерфейсе.

> **Важно:** веса нейросетевой модели не включены в репозиторий. Для запуска необходима исходная совместимая модель. Установка зависимостей сама по себе недостаточна.

## Статус проекта

Проект представляет собой **прикладной прототип**, созданный и продемонстрированный в ходе производственной практики. Исходный код был передан представителям организации для возможного дальнейшего использования и развития.

Masker не является промышленной или сертифицированной системой защиты персональных данных. Качество маскирования зависит от используемой модели и входного текста; полное обнаружение всех конфиденциальных сведений не гарантируется.
